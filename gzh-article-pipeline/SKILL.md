# 微信公众号全流程创作与发布流水线 (GZH Article Pipeline)

本 Skill 基于 9月24日破圈级爆款推文（[yt-dlp 深度解析文](https://mp.weixin.qq.com/s/J6uXtqTk8AhrJWPuYz6GIg)，分享率高达 11.45%）以及 10月9日破千阅读爆款（[GhostTrack 下载神器](https://github.com/xiaoyouchr/ghost-downloader-3)）提炼的最佳工程实践与视觉规范，形成一套高转化、高分享、排版高级、API 全自动化的微信公众号内容生产与发布闭环：

1. **爆款工程学叙事与去 AI 味写作 (`humanizer-zh`)**：
   - 击中全民级高频痛点（控诉流氓套路，制造受害者情绪共鸣）；
   - 四维黄金标题法 + 颠覆性认知解密（把技术讲成“降妖除魔的攻防爽文”）；
   - 包含超出预期的隐藏神技，文末交付“可抄作业的极简高频命令速查表 + 全维度对比表”，提供极高社交货币。
2. **AI 原生中文火柴人插图与科技杂志封面体系 (`stick-figure-illustrations`)**：
   - **封面视觉高级化重构（告别廉价大黄底，杜绝单调小黑板）**：
     - **底色规范**：默认首选**科技杂志冷灰白（#F5F6F8）**，兼具高级感与耐看性（硬核代码类主题备选 Slate 终端暗黑 `#0F172A`）；坚决摒弃刺眼廉价的大黄底，严禁使用杂乱背景以保障纯色无缝延伸；
     - **叙事分镜与丰富层次**：画面构建“左侧痛点反差（如打叉垃圾桶抛弃水课/报错终端）+ 右侧工匠实操（手搓积木/连接核心协议）+ 中央权威背书（黑金 Stars 徽章 + 翡翠绿/珊瑚红标签）”，拒绝干瘪单一的讲课构图；
     - **微信 2.35:1 安全视窗居中法则**：严格适配微信订阅号列表预览（居中 2.35:1 裁剪），所有核心文字与主体严格收缩在垂直中段 65% 安全视窗内（y: 100px ~ 470px），绝不切字。
   - **AI 原生中文强制约束（杜绝英文占位符）**：
     - 生图 Prompt 必须在 `TEXT ELEMENTS` 块中显式写明所需中文字符串（如 `"2999元 AI 爆款大师课"`、`"听我的，马上财富自由！"`），并添加 `(Render Chinese characters cleanly and legibly)`；
     - 严禁在 Prompt 中偷懒使用英文占位文字（如 `"Expensive AI Masterclass"`），防止模型生成全英文违规画面。
3. **经典「橄榄手记 (theme-olive-journal)」标准排版体系**：
   - 严格调用 `references/olive_journal_template.py` 组件库：
     - `section_title(num, title, sub)`：大号 PART 计数器 + 1px 细线分隔 + 纯黑标题 + 灰绿副标；
     - `p(text, align="justify")`：`IBM Plex Sans` 14px，行高 1.9，两端对齐；
     - `editors_note(tag, sub, text)`：暗夜控制台卡片（黑色状态栏 + 浅色底板）；
     - `quote_card(quote_text, author_title)`：4px 经典科技蓝边卡片；
     - `code_block(lang, code_lines)`：深色终端窗与代码命令；
     - `comparison_table(headers, rows)`：细线全屏对比大表；
     - `github_portal_card(...)`：高质感 GitHub 项目传送门卡片；
     - 自动化 `LeafWrapper` 校验，确保 100% `<span leaf="">` 包裹（0 Error 0 Warning）。
4. **微信公众平台 API 直连自动化**：
   - 自动将本地插图上传至微信官方 CDN (`media/uploadimg`)；
   - 自动上传封面图片至永久素材库 (`material/add_material`)；
   - 自动替换 HTML 内图片路径并一键推送到公众号草稿箱 (`draft/add`)。

## 双轨触发机制 (Dual Entry Trigger)

本流水线严格区分以下两种交互意图：

* **【模式 A：自主选题与今日规划模式】**
  * **触发时机**：用户未给具体项目链接，提出“今天选个题”、“给几个选题”、“按爆款准则选题”、“今天写什么好”；
  * **执行动作**：执行 **【阶段零：爆款选品准则与高转化选题引擎】**，严格按「高频痛点 × 降维免费 × 0门槛开箱即用」标准，输出 3 个高转化、高分享潜力的开源选题方案供用户挑选。
* **【模式 B：指定链接/项目直接写作模式】（原流水线保持不变）**
  * **触发时机**：用户直接提供了 GitHub 仓库地址、工具官网、文章链接或具体素材（例如：“写一篇介绍 https://github.com/... 的文章”）；
  * **执行动作**：**完全按照原有的标准流水线执行**，跳过阶段零，直接从 **【阶段一：阅读输入与视觉锚点规划】** 启动，顺次完成 Shot List 规划 ➔ 火柴人生图 ➔ 人性化写作 ➔ 橄榄手记排版 ➔ 自动推送草稿箱。

## 核心工作流 (标准化执行阶段)

### 阶段零：爆款选品准则与高转化选题引擎 (Topic Selection Engine - 模式 A 专用)

当用户要求“选题”或“今日规划”时，必须严格执行本准则筛选并推荐：

#### 1. 选品四象限法则（三必选与三不选）
* ❌ **三不选（严禁自嗨）**：
  1. **纯底层代码库/协议库不选**（如“Go 语言高性能协程池”、“某分布式 Raft 实现”，仅千分之一专业码农懂，零转发率）；
  2. **配置极繁琐/需手配环境不选**（需配 CUDA、编译 C++、复杂 Docker 报错劝退小白，完读率必崩）；
  3. **小众二次元/纯学术论文不选**（脱离本账号 36~60 岁成熟高知与职场骨干基本盘）。
*  **三必选（爆款基因）**：
  1. **跨平台全民高频痛点**：全网音视频下载/解密、格式转换、投屏互传、去水印、录屏剪辑；
  2. **降维白嫖平替商业流氓/昂贵订阅**：平替百度网盘/迅雷限速、平替付费 PDF 转换全家桶、平替昂贵云存储与 SaaS 订阅；
  3. **视觉/交互惊艳且开箱即用**：带高质感现代 UI、跨 Windows/macOS、提供编译好的 Release 双击即开，小白 10 秒上手。

#### 2. 算法裂变与社交货币审查 (Social Currency Gate)
每个推荐选题必须明确回答：**读者读完后，会以什么具体理由一键转发到哪个微信群？**
- **利他备忘型**：工具太实用，读者必须“转发给微信好友/文件传输助手/收藏”备用；
- **群聊解难型**：发到公司群、技术群、好友群秒解群友刚需（如“谁有不限速下载 4K 的工具”）；
- **极客品味型**：展现自己懂开源、有门路、认知超前。

#### 3. 选题输出标准化交付物 (Deliverable)
每次向用户汇报 3 个候选选题，每个选题必须包含：
- **【项目名与链接】**：GitHub 地址、最新 Stars 数、跨平台支持度；
- **【受害痛点与降维打击】**：被什么商业软件恶心、该工具如何秒杀解决；
- **【3 套黄金标题备选】**：
  - *套路 A（怒怼行业痛点）*：`《别再给XX交智商税了！这款GitHub万星神器，彻底终结了所有套路》`
  - *套路 B（情绪爽点 + 极度直白）*：`《全网任意下、无视会员限制？实测完这款开源神作，我把收费软件全删了》`
  - *套路 C（降维打击 + 0门槛）*：`《这才是顶级工具该有的样子！零广告、全平台4K拉满、连小白都会用》`
- **【群聊转发理由】**：读者转发的精准动机。

### 阶段一：阅读输入与视觉锚点规划 (Planning & Shot List - 模式 B 保持原样)
1. **解析输入**：读取用户提供的 Markdown 文件、URL 链接内容（使用 `read_url_content`）、文字草稿或主题大纲；
2. **核心受众画像校准（严禁纯技术自嗨）**：
   - 本账号粉丝基本盘为 **36~60岁成熟职场骨干/技术管理者 (73.7%)、男性 (91.6%)、一二线城市高知盘**；
   - **痛点特征**：受够了日常繁琐的文档、表格、数据清洗、多系统协同等“数字脏活”，渴望开箱即用，厌恶复杂折腾与套壳套路；
   - **四纵选题阵列映射**：
     - *阵列一：文档与报告内耗神器*（扫描件/模糊OCR/PDF表格提取/本地会议纪要提炼）；
     - *阵列二：表格、数据清洗与自动化*（发挥大数据背景，几万行Excel秒合并/轻量脚本防报警/免安装数据大屏）；
     - *阵列三：本地离线、安全不泄密高阶生产力*（断网可用大模型/团队轻量私有云/开源平替昂贵订阅软件）；
     - *阵列四：国家级/顶尖巨头破局大叙事*（如 America.gov，顶层数字治理架构与宏观趋势）。
3. **社交货币动机审查 (Social Currency Gate)**：
   - 选题立项前必须回答核心问题：**“读者读完，会以什么具体理由、一键转发到哪类微信群？”**
     - **管理型转发**：主管转到部门群当工作抓手（“以后这类材料统一用这个工具处理，省下几万采购费”）；
     - **品味型转发**：高知转到行业群或朋友圈当社交勋章（“这才是数字化架构终局，一个统一智能路由足矣”）。
   - 若缺乏具体转发场景，必须重构切入角度。
4. **标题策略双轨制规划**：
   - **Track A (高对抗大字报体)**：`[极致爽点/0门槛利益]！[万星权威背书] [情绪催化词]，[反常识/震撼结果]！`（适合痛点反弹强烈、大众工具类题材）；
   - **Track B (极简大叙事陈述体)**：`[权威/顶尖机构] + [大尺度数量/复杂繁琐体系] + [极简化动作] + [单个AI/工具产品]`（零感叹号，客观平实却震撼，自带《连线》《纽约客》大报头条质感，适合国家队/大厂/重磅架构题材）。
5. **提炼核心认知转折点与痛点反差**：找出全民级痛点、反常识技术底座、猫鼠攻防博弈点；
6. **规划流量与互动设计**：
   - **设计留言区盖楼议题**：抛出能引发强烈踩坑共鸣或观点讨论的话题，拉高留言数与互动分；
7. **输出规划表格 (Shot List)**：严格使用规范生成候选配图方案表格，**并在 Labels 中明确写出需要 AI 直接绘制的中文文本**：
   `| # | Priority | Placement | Canvas | Theme | Core idea | Composition pattern | Stick-figure action | Emotion | Main objects | Labels (AI 原生中文字符) | Generate? |`
   - **封面设计要求**：必须在 Shot List 中注明 `16:9 (2.35:1 居中安全视窗)`，标明主标题横幅与副标；
8. **强制停顿确认**：输出推荐首选图并提供交互选项（如 `确认方案并生成` / `调整 #1`），**等待用户明确确认后，方可进入下一阶段**。

### 阶段二：深度人性化写作 (Humanized Writing)
用户确认规划方案后，结合 **`humanizer-zh`** 与爆款工程学进行深度撰写：
- **拒绝 AI 腔调与自嗨黑话（老妪能解原则）**：
  - 严禁掉书袋和堆砌抽象术语（如“多模态视觉版面分割”、“私有化量化部署”、“多Agent协同路由”）；
  - **必须用「生活化比喻」搭桥**：把技术讲成普通人、财务、HR、行政小白都能秒懂的大白话（例如：“透视眼撕贴纸贴到Excel”、“断网保密秘书”、“政务大厅门口的热心老干部”）；
  - 禁止使用“不仅……而且……”、假大空三段式排比、“在这个数字化时代”、“至关重要”、“织锦”、“双刃剑”等套话；
- **爆款叙事节奏与流量池指标设计**：
  1. *序章（抓紧前 200 字）·还原“带体温的真实受害现场”*：
     - 拒绝抽象说理，必须写出**具体时间节点、具体角色、具体恶心细节**（如“周五晚8点40准备下班，业务部门突然甩来一个200页双栏扫描PDF……”），让成熟职场人第一秒产生“作者跟我坐同一间办公室挨过打”的极强共鸣；
  2. *绝活一（极客反差与最后 1 公里傻瓜式交付）*：
     - 纯粹开源体验与商业流氓全家桶形成剧烈反差；
     - **消灭小白三大恐惧**（主动说明：不弄坏电脑、无扣费陷阱、不泄露隐私）；
     - **纯白话极简三步法**（解压 ➔ 双击启动 ➔ 把文件拖进浏览器），消灭一切命令行、Docker 与配置环境报错；
  3. *绝活二（颠覆认知）*：用生活比喻拆解底层原理（“为什么以前做不到？”）；
  4. *绝活三：三维硬核真机实测（Edge-Case Torture Test）*：
     - **拒绝空洞吹捧，端出 3 个刁钻场景实测**：
       - ① **读者群体切身利害场景**（如留学生/工程师办绿卡流程、科研党提取古老双栏扫描论文）；
       - ② **极限冷门规则考核**（考核工具懂不懂行业隐形“死知识”或跨页复杂嵌套大表）；
       - ③ **设计边界与模型底线探测**（测试断网离线表现、隐私截留、幻觉率与趣味彩蛋）；
     - 可配合 `test_case_card` 组件展示真实提问、回答要点与证据链；
  5. *绝活四（坦白 20% 的缺点与边界）*：
     - 杜绝“100%完美秒杀一切”的无脑吹嘘；主动指出“倾斜超15度会识别不稳”、“8G旧机器批量跑CPU占用90%”等真实短板。克制与诚实才是最高级的专业说服力；
  6. *速查表与对比表*：提供可直接抄作业的 5~6 条高频神仙命令/傻瓜操作表，以及四维全方位代际对比大表（促成收藏与划线）；
  7. *尾声互动*：自然过渡到开源传送门与留言区互动，发起高智商行业讨论。
- **写作自查“五拷问”清单**：
  - [ ] 痛点够不够惨？（第一段是否写出具体憋屈的受害现场？）
  - [ ] 话讲得够不够白？（是否彻底消灭了冷门术语？不懂代码的行政/业务小白能不能一口气读懂？）
  - [ ] 缺点敢不敢讲？（是否坦白了边界与不适用场景？）
  - [ ] 门槛够不够低？（是否做到开箱即用，消灭了配置环境的阻力？）
  - [ ] 转出去体不体面？（读者转到群聊或朋友圈，能否彰显其专业度或管理力？）

### 阶段三：视觉生成与公众号内联排版 (Generation & Formatting)
0. **生图双引擎调用准则与 429 容灾兜底铁律（重中之重）**：
   - **第一梯队（默认优先）**：直接调用 Native Tool `generate_image`（必须传参 `AspectRatio: "16:9"`），极速生成高精原图；
   - **第二梯队（当触发 429 频率超限、额度耗尽或生图报错时）**：
     - 🚨 **绝对禁止违规降级**：严禁自行降级使用 Python PIL 代码绘制僵硬的表格、方框或文字框当配图/封面！严禁放弃生图或使用空白占位符！
     - 🚀 **强制切换浏览器原生生图**：必须立即自动调用 `scripts/gemini_web_bridge.py` 中的 `generate_image_via_gemini_web(prompt, output_file_path)`；
     - **运行机制**：该桥接脚本通过 macOS 原生 AppleScript 操控 Google Chrome 中已登录的 Gemini Pro / Advanced 网页端会话，自动注入 Prompt、等待渲染并从 Canvas 捕获无损原图，100% 绕开 API 的 429 配额限制，保证封面与插图永远是高品质手绘艺术图。
1. **配图矩阵组合拳（双轨咬合与高级视觉）**：
   - **手绘火柴人（情绪与反差担当）**：负责封面大字报、开篇痛点控诉、结尾爽点收官，由生图模型原生渲染中文字符；
     - 🚨 **Prompt 中文硬性指令军规**：生图 Prompt 必须显式声明中文字符串，严禁使用英文占位符！示例模板：
       ```text
       TEXT ELEMENTS (Render Chinese characters cleanly and legibly):
       Clear handwritten Chinese text on board: "2999元 AI 爆款大师课"
       Speech bubble from stick figure in Chinese: "听我的，马上财富自由！"
       ```
   - **真机实操截屏长图/动图（事实与信任担当）**：用于实测章节、官方架构解析，提供原汁原味的真实证据链；
   - **【封面绝对工业红线：五层叙事剧场版视觉工程学 + 2.35:1 安全视窗（实测万读标杆）】**：

### 阶段四：一键推送微信公众号草稿箱 (WeChat Draft Publishing)
当排版与图片准备就绪后，直接运行发布脚本：

```bash
# 模式 A：首次推送到草稿箱（新建草稿）
python3 <skill_dir>/scripts/upload_to_wechat.py \
  --html "<排版好的HTML绝对路径>" \
  --images-dir "<图片所在目录>" \
  --title "<文章标题>" \
  --author "奇点造物所" \
  --digest "<120字以内的精准摘要>" \
  --cover "<封面图绝对路径>"

# 模式 B：覆盖更新已有草稿（防劣化覆写模式，修改标题/摘要/封面时专用）
python3 <skill_dir>/scripts/upload_to_wechat.py \
  --html "<本地重新编译的完整HTML路径>" \
  --images-dir "<图片所在目录>" \
  --title "<更新后的标题>" \
  --author "奇点造物所" \
  --digest "<更新后的摘要>" \
  --update-draft "<已有草稿的 media_id>" \
  --cover "<新封面路径（若封面未改可使用 --reuse-thumb <已有thumb_id>）>"
```

**草稿箱更新防劣化铁律（Draft Update Idempotency）**：
- 🚨 **严禁使用 `draft/get` 回传更新**：当需要修改草稿标题、摘要或封面时，**绝对禁止从 `draft/get` 取出已清洗的内容传回给 `draft/update`**！微信每次回传都会产生实体转义雪崩（如 `&#39;` 导致整个 section 的 `style=""` 被清空）；
- **始终基于本地干净源文件更新**：必须使用 `upload_to_wechat.py --update-draft <media_id>`，始终以本地刚刚编译生成的无损 HTML + 微信 CDN 图片链接进行覆盖更新，保证排版、边框与底色 100% 稳定完好。

**脚本自动执行以下操作**：
1. 请求微信服务器获取有效 `Access Token`；
2. 上传封面图片获取永久素材 `thumb_media_id`；
3. 将 HTML 内所有引用的本地插图上传至微信官方 CDN（`media/uploadimg`），并全自动完成 URL 替换；
4. 调用 `draft/add` 接口提交图文，返回 `Draft Media ID`；
5. 向用户反馈提交结果与公众平台查看路径。
