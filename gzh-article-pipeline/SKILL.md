# 微信公众号全流程创作与发布流水线 (GZH Article Pipeline)

本流水线采用模块化渐进式调度架构，实现从选题策划、视觉生成、人性化写作、高质感排版到官方草稿箱直推的全闭环自动化。

---

## 双轨触发机制 (Dual Entry Trigger)

* **【模式 A：自主选题与今日规划模式】**
  * **触发时机**：用户未给具体链接，提出“今天选个题”、“给几个选题”、“按爆款准则选题”、“今天写什么好”；
  * **执行动作**：执行 **【阶段零：爆款选品准则与高转化选题引擎】**，输出 3 个符合 S/A 级公约数的候选方案。
* **【模式 B：指定链接/项目直接写作模式】**
  * **触发时机**：用户直接提供 GitHub 仓库、官网、文章链接或素材（如：“写一篇关于 BCUninstaller 的文章”）；
  * **执行动作**：直接从 **【阶段一：阅读输入与视觉锚点规划】** 启动，顺次执行完整流水线。

---

## 核心工作流 (标准化执行阶段)

### 阶段零：爆款选品准则与高转化选题引擎 (模式 A 专用)
> 🚨 **渐进加载指令**：执行本阶段前，必须调用 `view_file` 查阅 `references/topic_selection.md`（包含 GhostTrack 2万读、GhostDownloader 7.2千读实战模型、六道立项生死门与平台版权防火墙）。
1. **象限与六门审查**：首要通过 **门禁 0（商业防火墙与版权自杀门）**，严禁触碰腾讯 TME 周杰伦/QQ音乐VIP、腾讯视频VIP及微信生态外挂；严选第 I 象限（全民痛点+反逼氪情绪）与第 II 象限（搞钱/防忽悠刚需）开源标的，依次通过基数门、炸药门、开箱门、奇迹门、社交门，一票否决第 IV 象限自嗨题材；
2. **千次转发社交货币审查**：确保预期分享率 > 10%（冲刺 1,000 次群聊转发阈值），明确具体的群聊转发第一句话；
3. **输出标准化交付物**：汇报 3 个候选选题，包含象限评级、受害痛点、奇迹时刻、3 套黄金母版备选标题与转发动机。

---

### 阶段一：阅读输入与视觉锚点规划 (Planning & Shot List)
1. **解析输入**：通过 `read_url_content` 或本地文件读取目标素材；
2. **受众画像与标题铁律（严格 <= 26 字符）**：校准 36~60 岁高知男性画像，规划 Track A (大字报对抗体) 或 Track B (极简大叙事陈述体)，标题字符数严格限制在 26 字以内（防微信列表折叠），必须嵌入 NLP 暴击词（恶心吐了/流氓/坑爹/一键/秒级/万星）；
3. **输出 Shot List 表格**：输出标准配图矩阵表格（含 16:9 居中 2.35:1 安全视窗封面及正文插图）；
4. **强制停顿确认**：等待用户明确确认配图方案后，方可进入下一阶段。

---

### 阶段二：深度人性化写作 (Humanized Writing)
> 🚨 **渐进加载指令**：执行本阶段前，必须调用 `view_file` 查阅 `references/writing_playbook.md`。
1. **消灭 AI 腔调**：老妪能解原则，消灭堆砌术语，全面采用生活化比喻；
2. **算法三大指标与社群裂变埋点**：
   - **完读率锁死**：前 200 字还原带体温的“挨打现场”，每 400~500 字插入高密度卡片重置心流；
   - **划线率埋点**：显式设计 2~3 处反直觉认知金句（荧光笔划线专供）；
   - **分享率与社群裂变硬资产**：文末强制提供单屏手机可截下的《四维全维度代际对比大表》、0 门槛开箱直接用指引，以及**文末预埋【一键复制群聊安利词】**（冲刺 1,000 次群聊转发阈值）；
   - **120 字痛点摘要**：严格限制 80~120 字，遵循“痛点场景+后果+开源降维手段+利益点”公式（非关注流推荐转化核心）；
3. **执行“八拷问”清单自查**：确保标题合规、痛点惨、大白话、有边界、交付单屏硬资产与现成安利词。

---

### 阶段三：视觉生成与公众号内联排版 (Generation & Formatting)
> 🚨 **渐进加载指令**：生图与封面设计查阅 `references/visual_system.md`；广告心流埋点查阅 `references/traffic_monetization.md`。
1. **视觉生成双引擎与零延迟自动降级（严禁等待用户提醒）**：
   - 默认优先尝试 API 生图或调用统一调度器 `scripts/generate_image_unified.py`；
   - 🚨 **429 额度耗尽自动容灾铁律**：一旦遇到 429 `RESOURCE_EXHAUSTED` 或配额报错，**严禁中断流程、严禁向用户报错等待提示**！必须**在后台立刻无缝自动调用** `python3 scripts/gemini_web_bridge.py --prompt "..." --output "..."`，直接复用 Chrome 中用户已登录的 Gemini Web Pro (Google One AI Premium) 会话自动打词并截获高清原图，实现完全无人值守的全流程自动保底！
2. **封面剧场版标准**：严格执行五层叙事架构（标签、主标题、具象副标、背书徽章、利益药丸）与垂直中段 65% 安全视窗；
3. **内联 HTML 组装**：调用 `references/olive_journal_template.py`（橄榄手记），组装文末三大闭环卡片（开源传送门、盖楼提问、号主介绍）；
4. **格式合规校验**：运行 `LeafWrapper` 与 `LeafValidator`，确保 100% `<span leaf="">` 包裹（0 Error 0 Warning）。

---

### 阶段四：一键推送微信公众号草稿箱与定时门禁调度 (Publishing & Timing Gate)
排版与图片准备就绪后，直接运行发布脚本，并执行**发文时段门禁调度器**：

```bash
# 模式 A：首次推送到草稿箱（新建草稿）
python3 /Users/qcc/.gemini/config/skills/gzh-article-pipeline/scripts/upload_to_wechat.py \
  --html "<排版好的HTML绝对路径>" \
  --images-dir "<图片所在目录>" \
  --title "<文章标题（严格<=26字）>" \
  --author "奇点造物所" \
  --digest "<80~120字以内的四要素痛点摘要>" \
  --cover "<封面图绝对路径>"

# 模式 B：覆盖更新已有草稿（防劣化覆写模式，修改标题/摘要/封面时专用）
python3 /Users/qcc/.gemini/config/skills/gzh-article-pipeline/scripts/upload_to_wechat.py \
  --html "<本地重新编译的完整HTML路径>" \
  --images-dir "<图片所在目录>" \
  --title "<更新后的标题（严格<=26字）>" \
  --author "奇点造物所" \
  --digest "<更新后的摘要>" \
  --update-draft "<已有草稿的 media_id>" \
  --cover "<新封面路径（若封面未改可使用 --reuse-thumb <已有thumb_id>）>"
```

推送草稿箱完成后，必须显式在回复中提示用户建议的定时群发时间与推荐文案：
* 👑 **【首选发射窗：07:00 ~ 07:20】**：历史平均阅读 **2,250.9**，享有 16 小时完整白天发酵期，冲锋型核武器必须在此窗口发出！
* 🌙 **【备选发射窗：20:45 ~ 21:15】**：晚间休闲娱乐档，视听、音乐类神器的优选窗口。
* 🛑 **【绝对死亡禁区：09:30 ~ 11:30】**：历史 60 篇平均阅读仅 140~280，职场早会与清邮件高压黑洞，严禁在此窗口群发主力文章！
* 📅 **【周内节奏战术】**：周五/周六早晨为核武器爆发日；周一全网高压（历史均阅 69.4），严禁排冲锋大题材。

## 顶级不可逾越全局红线 (Top-8 Global Rules)

1. 🚨 **商业防火墙与版权自杀一票否决**：绝对严禁在腾讯微信平台上立项白嫖腾讯自身核心商业利益与独家版权的内容（严禁碰 TME 周杰伦/QQ音乐SVIP破解、腾讯视频VIP破解、微信自动化外挂等），防止公域推流被底层封杀及触发《微信公众平台运营规范 4.1.2 条 - 内容侵权》直接强删封号！
2. 🚨 **标题字符绝对锁死 <= 26 字**：严禁超长导致在微信常读卡片、群分享卡片中被省略号截断；
3. 🚨 **CSS 绝对防清洗**：内联样式中严禁出现单引号 `'`，必须使用通用无引号字体族，避免 `style=""` 被服务端清空；
4. 🚨 **行内高亮防折断**：`hl()` 仅限 10 字以内短词，跨行长句严禁套用边框高亮；
5. 🚨 **生图原生中文**：Prompt 必须显式声明中文文本，严禁使用英文占位符；
6. 🚨 **封面 2.35:1 居中防切字**：所有文字元素严格收敛在垂直 18%~83% 安全视窗内；
7. 🚨 **严禁伪 AI 装饰**：严禁在正文顶部添加机械日期条/专栏标，严禁使用“CASE 01 //”代码标号，严禁往期推荐或回复自取卡片；
8. 🚨 **禁发死亡时段与底层代码一票否决**：严禁在 09:30~11:30 发射主力文章；严禁选择纯底层代码/架构库/B2B 企业级运维等无全民共鸣的自嗨题材。
