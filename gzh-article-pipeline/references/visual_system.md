## 一、 生图双引擎调用准则与 429 容灾兜底铁律

1. **第一梯队（默认优先）**：
   - 直接调用 Native Tool `generate_image`（传参 `AspectRatio: "16:9"`），极速生成高精原图；
2. **第二梯队（当触发 429 频率超限、额度耗尽或生图报错时）**：
   - 🚨 **绝对禁止违规降级**：严禁自行降级使用 Python PIL 代码绘制僵硬的表格、方框或文字框当配图/封面！严禁放弃生图或使用空白占位符！
   - 🚀 **强制切换浏览器原生生图**：必须立即自动调用 `scripts/gemini_web_bridge.py` 中的 `generate_image_via_gemini_web(prompt, output_file_path)`；
   - **运行机制**：该桥接脚本通过 macOS 原生 AppleScript 操控 Google Chrome 中已登录的 Gemini 网页端会话，自动注入 Prompt、等待渲染并从 Canvas 捕获无损原图，100% 绕开 API 的 429 配额限制，保证封面与插图永远是高品质手绘艺术图。

## 三、 彩色精修暴走漫画火柴人视觉规范（2026-11-12 最新定稿标准 · 封面与正文通用）

> 🚨 **核心美学铁律**：彻底告别“单薄简陋白纸细线火柴人 + 悬浮 ❌/✅ 圆圈 + 多色俗气金丝带五层堆砌”，封面与后续所有正文火柴人插图统一升级为**「彩色精修暴走漫画火柴人（Rage Comic Stick-Figure Editorial）」**。

### 1. 角色造型与质感铁律（必须纯正火柴人，绝不画成写实人类）
* **头部与身形红线**：主角**必须是光滑纯白圆球脑袋 + 细长管状四肢的火柴人**（🚨 严禁给火柴人画真人头发、耳朵、写实肤色鼻梁或宽大肌肉肩膀！）。
* **表情包灵魂（暴走漫画风）**：五官采用极度夸张搞笑的中国暴走漫画（Rage Comic）经典表情：
  * **左侧痛点人物**：瞳孔地震、张嘴喷泪哭喊、脑门冒青筋/冒烟、满头大汗、头晕蚊香眼；
  * **右侧破局人物**：戴酷黑墨镜、露出经典“姚明嘲讽狂笑 / 狂喜爽笑”表情，跷二郎腿端冰美式或悠闲操作。
* **逼真上色与材质**：告别死板纯白纸片！火柴人身体采用**漫画网点 + 立体明暗阴影**体现体积感；手中道具（发红告警的手机、Windows 桌面大屏、Switch 游戏画面、散落发票/文件堆、书卷、咖啡杯等）必须**高饱和写实上色、带光晕反光与环境氛围质感**。

### 2. 封面「暴漫大字特写冲击风」不对称构图铁律（2026-11-23 升级定稿）
* 🚨 **彻底废弃“暗色背景 + 顶部细长小胶囊 + 居中黄字 + 中间小火柴人”三段式套娃模板**：在公众号后台与信息流里，沉闷暗色居中海报既显压抑又显廉价套路。新封面统一升级为 **左超大字 + 右大特写（Asymmetric Comic Pop Close-Up）**：
  * **左侧（约 52% 画面宽度）— 超大左对齐两行标题 + 高对比斜切色带**：
    * 主标题拆成极简醒目的 **两行超大黑粗/白粗漫画描边字**（如 `合同离线改` / `绝不上传!` 或 `断网存密码` / `才最安全!`，手机缩略图里 0.3 秒一眼看穿）；
    * 下方紧贴一条 **微倾斜高饱和色带横幅**（如翡翠绿/警示红/电光黄），交代权威背书与收益，如 `1.6万星开源 · 120项PDF全免费`；
    * **严禁** 顶部悬浮细长小胶囊、严禁三层对称居中小字。
  * **右侧（约 48% 画面宽度）— 超大特写夸张火柴人 + 实体道具互动**：
    * 主角火柴人**贴近镜头半身/大头特写**（戴酷黑墨镜狂笑/得意挑眉/紧抱核心道具），与极具辨识度的高饱和实物（如**红色本地加密印章与合同纸**、**镀金银行金库钥匙与保险箱转盘**、**开源声波监听麦克风**、**实体游戏掌机**）发生强动作互动；
    * 背景铺设动态 **漫画网点（Halftone Dots）+ 放射状速度线（Comic Speedlines）**，整张图明快通透、冲击力拉满。
  * **色彩明快与强对比（禁止灰暗压抑泥淖感）**：主背景优先选用亮暖米白 `#FFFDF5` 撞翡翠绿/珊瑚红、电光钴蓝 `#165DFF` 撞明黄/正红、亮橙 `#FF6B00` 撞天青等高饱和明快漫画色板，杜绝大面积低亮度暗灰/死气暗绿。

### 3. 封面 16:9 安全构图转 21:9 (2.35:1) 不裁边与正文区分规范
* **封面先以 `16:9` 高精生图再无损转 `2.35:1` 全景横幅**：由于生图工具原生支持 `16:9`（不支持直接输出 `21:9`），生图时必须将主标题、色带与右侧特写主体收敛在垂直 `13%~87%`、水平 `8%~92%` 安全区内；随后通过纯色/平滑渐变+同角几何网点/速度线无缝外延为 `2.35:1`（如 `1805×768`），**严禁横向拉伸单列边缘像素产生横条纹拖影**；上传时固定使用 `--no-safe-crop` 原图直传，彻底杜绝草稿箱或信息流切头切字。
* **正文漫画插图规范（16:9）**：正文漫画配图保留清爽 `#F3F5F7` / `#FBFBF7` 浅灰/米白漫格纸面质感，避免重色底抢夺橄榄手记正文白底阅读视觉，顶部或分格标出清晰中文流程对比。

### 4. 底色、构图与角色「一文一色一道具」防同质化铁律
* 🚨 **绝对禁止千篇一律模板套用**：每篇文章必须根据主题更换 **全新亮彩配色板 + 专属火柴人配饰/动作 + 核心实体道具**，禁止连续两篇同色同道具：
  * **合同/PDF/办公文档类**：亮米白纸面底 + 翡翠绿/珊瑚红网点；火柴人戴 **绿色透明审单遮阳帽 + 墨镜** 手持巨型红印章猛盖合同；
  * **密码/账密/隐私安全类**：电光钴蓝放射底 + 鎏金/正红丝带；火柴人握 **超大镀金银行保险箱钥匙** 守住 `KDBX` 钢铁金库门；
  * **影视 / 视频剪辑类**：皇家宝蓝/电光紫聚光灯 + 金色大剪刀/导演贝雷帽与场记板；
  * **语音 / 录音办公类**：亮橙/明黄 + 薄荷青撞色；火柴人戴 **监听大耳机** 在麦克风前一键转文字；
  * **装机清理 / 卸载除流氓类**：净澈天蓝白 + 亮橘警示气泡；火柴人扛 **推土机/大吸尘器** 清走弹窗图标；
  * **游戏 / 跨端串流类**：赛博霓虹青 + 电光紫红；火柴人狂笑举着 **实体掌机/手柄** 贴脸特写；
  * **历史 / 人文 / 地图类**：温润宣纸米黄 + 朱砂红印 + 墨绿线框；火柴人持 **古风卷轴/放大镜** 指点山河图。

## 五、 爆款封面 7 维出图与发前视觉终检清单

每次生成或选定公众号封面后，必须用原生看图能力逐一核验以下 **7 项视觉卡扣**（任一不达标直接重生成，严禁将就推送）：

1. **文字内容与零错字**：大字标题全中文、无乱码生造字、无冷门黑话（路人 0.5 秒能秒懂解决什么事）；
2. **主体元素与人物情绪**：白圆头火柴人完整未变成写实人类，暴漫表情（愤怒崩溃 vs 墨镜炫笑）对比强烈；
3. **色彩对比与去廉价感**：三段式色彩主次清晰，禁用大块纯黄刺眼底或五颜六色丝带堆积；
4. **构图留白与居中安全框**：核心文字收敛在垂直 `18%~83%` 安全视窗内，左右火柴人完整踩在地面投影上、不贴边切脚；
5. **视觉风格一致性**：正文若采用「实机界面截图 + 暴漫火柴人」，色调协调、无违和水印；
6. **点击诱因明确**：一眼能看出「省了多少钱 / 释放了多少空间 / 解决了什么恶心事」；
7. **尺寸与文件体积**：`21:9` 横版全景（`1024×434` 等比），单图文件严格 `< 1MB`（防微信 `uploadimg` CDN 超限失败）。\n
