# AI 原生火柴人视觉工程学与封面标准 (Visual Design System)

> 本指南用于指导微信公众号插图规划、AI 原生中文生图、剧场版封面分层设计及 2.35:1 裁切适配。

---

## 一、 生图双引擎调用准则与 429 容灾兜底铁律

1. **第一梯队（默认优先）**：
   - 直接调用 Native Tool `generate_image`（传参 `AspectRatio: "16:9"`），极速生成高精原图；
2. **第二梯队（当触发 429 频率超限、额度耗尽或生图报错时）**：
   - 🚨 **绝对禁止违规降级**：严禁自行降级使用 Python PIL 代码绘制僵硬的表格、方框或文字框当配图/封面！严禁放弃生图或使用空白占位符！
   - 🚀 **强制切换浏览器原生生图**：必须立即自动调用 `scripts/gemini_web_bridge.py` 中的 `generate_image_via_gemini_web(prompt, output_file_path)`；
   - **运行机制**：该桥接脚本通过 macOS 原生 AppleScript 操控 Google Chrome 中已登录的 Gemini 网页端会话，自动注入 Prompt、等待渲染并从 Canvas 捕获无损原图，100% 绕开 API 的 429 配额限制，保证封面与插图永远是高品质手绘艺术图。

## 二、 AI 原生中文强制约束（杜绝英文占位符）

生图 Prompt 必须在 `TEXT ELEMENTS` 块中显式写明所需中文字符串，严禁使用英文占位符：
```text
TEXT ELEMENTS (Render Chinese characters cleanly and legibly):
Clear handwritten Chinese text on board: "2999元 AI 爆款大师课"
Speech bubble from stick figure in Chinese: "听我的，马上财富自由！"
```

## 三、 彩色精修暴走漫画火柴人视觉规范（2026-11-12 最新定稿标准 · 封面与正文通用）

> 🚨 **核心美学铁律**：彻底告别“单薄简陋白纸细线火柴人 + 悬浮 ❌/✅ 圆圈 + 多色俗气金丝带五层堆砌”，封面与后续所有正文火柴人插图统一升级为**「彩色精修暴走漫画火柴人（Rage Comic Stick-Figure Editorial）」**。

### 1. 角色造型与质感铁律（必须纯正火柴人，绝不画成写实人类）
* **头部与身形红线**：主角**必须是光滑纯白圆球脑袋 + 细长管状四肢的火柴人**（🚨 严禁给火柴人画真人头发、耳朵、写实肤色鼻梁或宽大肌肉肩膀！）。
* **表情包灵魂（暴走漫画风）**：五官采用极度夸张搞笑的中国暴走漫画（Rage Comic）经典表情：
  * **左侧痛点人物**：瞳孔地震、张嘴喷泪哭喊、脑门冒青筋/冒烟、满头大汗、头晕蚊香眼；
  * **右侧破局人物**：戴酷黑墨镜、露出经典“姚明嘲讽狂笑 / 狂喜爽笑”表情，跷二郎腿端冰美式或悠闲操作。
* **逼真上色与材质**：告别死板纯白纸片！火柴人身体采用**漫画网点 + 冷灰立体明暗阴影**体现体积感；背景采用干净浅灰 `#F3F5F7` 配放射状漫画速度线；手中道具（发红告警的苹果手机、银色 MacBook、ELM327 汽车插头、Switch 与 3A 游戏画面、褶皱账单、亮灯仪表盘等）必须**高饱和写实上色、带高光反光与细节质感**。

### 2. 封面极简协调三段式排版（摒弃五层杂乱彩条与 ❌/✅ 贴纸）
* **禁止元素**：严禁在角落放悬浮红色 ❌ / 绿色 ✓ 大圆圈；严禁叠加 4~5 条红黑金绿彩带丝带（极易显得简陋模板化）。
* **标准三层居中架构**：
  1. **顶部深炭黑小胶囊（`#111827`）**：左侧配一个协调的小彩标（绿微信/黄扳手/手柄图标），文案为简洁属性定位，如 `开源神器 · 微信 4.x 原生可用`；
  2. **核心两行粗黑大字（#0F172A + 干净白描边与微投影）**：高对比度直击痛点与爽点（<= 2 行），不压挡人物与道具；
  3. **底部单条微信绿胶囊（`#07C160`）**：浓缩核心价值清单，如 `聊天 · 语音 · 朋友圈全备份 · 纯本地Win/Mac`。

### 3. 封面原生 21:9 (2.35:1) 全身不裁边防线
* **首选原生 2.35:1 全景横幅生图**：生图时直接指定 `21:9 宽高比（2.35:1 微信公众号头图全景横幅，如 1024×434）`，左右两个火柴人**全部画成完整全身小人踩在各自淡淡椭圆形地面阴影上**（四周与上下留足 `#F3F5F7` 呼吸边距，绝不贴底边裁断双脚、椅子、背包或账单），配合 `--no-safe-crop` 原图直传，100% 避免在草稿箱与订阅号信息流中被切掉半截。
* **正文火柴人插图规范（16:9）**：延续同款**纯白圆头暴漫表情 + 网点明暗 + 逼真上色道具**，顶部配一行居中加粗漫画标题栏讲透场景/工作流原理。

### 4. 底色规范（摒弃廉价大黄底）
默认首选**质感浅灰漫画速度线背景（#F3F5F7）**，严禁使用廉价刺眼大黄底或粗黑框，确保视觉精致吸睛且与“橄榄手记”正文调性高度统一。
