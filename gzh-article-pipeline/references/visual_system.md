# AI 原生火柴人视觉工程学与封面标准 (Visual Design System)

> 本指南用于指导微信公众号插图规划、AI 原生中文生图、剧场版封面分层设计及 2.35:1 裁切适配。

---

## 一、 生图双引擎调用准则与 429 容灾兜底铁律

1. **第一梯队（默认优先）**：
   - 直接调用 Native Tool `generate_image`（传参 `AspectRatio: "16:9"`），极速生成高精原图；
2. **第二梯队（当触发 429 频率超限、额度耗尽或生图报错时）**：
   - 🚨 **绝对禁止违规降级**：严禁自行降级使用 Python PIL 代码绘制僵硬的表格、方框或文字框当配图/封面！严禁放弃生图或使用空白占位符！
   - 🚀 **强制切换浏览器原生生图**：必须立即自动调用 `scripts/gemini_web_bridge.py` 中的 `generate_image_via_gemini_web(prompt, output_file_path)`；
   - **运行机制**：该桥接脚本通过 macOS 原生 AppleScript 操控 Google Chrome 中已登录的 Gemini 网页端会话，自动注入 Prompt、等待渲染并从 Canvas 捕获无损原图，100% 绕开 API 的 429 配额限制，保证封面与插图永远是高品质手绘艺术图。

---

## 二、 AI 原生中文强制约束（杜绝英文占位符）

生图 Prompt 必须在 `TEXT ELEMENTS` 块中显式写明所需中文字符串，严禁使用英文占位符：
```text
TEXT ELEMENTS (Render Chinese characters cleanly and legibly):
Clear handwritten Chinese text on board: "2999元 AI 爆款大师课"
Speech bubble from stick figure in Chinese: "听我的，马上财富自由！"
```

## 三、 封面五层叙事剧场版视觉工程学（实测万读标杆）

### 1. 核心 IP / 项目中文名显式置顶法则 (No Anonymous Tools)
封面主标题，**必须显式出现被拆解项目的正式中文全称**（带双书名号，例如 `《高性价比人生指南》`、`《BCUninstaller》`），绝不可只写泛化空泛的“【拒绝割韭菜】”或仅有数字！读者刷信息流首先要一眼锁定具体神作 IP。

### 2. 五层严谨叙事层级 (5-Tier Architecture)
* **Tier 1 (场景属性标签 Tag)**：顶部居中珊瑚红（`#E06D53`）场景标签，如 `【反诈与隐私防身】`、`【极客省钱与认知防身】`，一眼锁定读者痛点场景；
* **Tier 2 (主行动大标题 Title)**：大号加粗黑体，必须包含《项目正式中文全称》+ 破局核心动词，如 `《高性价比人生指南》· 12万星极客避坑圣经`；
* **Tier 3 (具象证据副标题 Subtitle)**：中号黑体，提供具体量化数字与覆盖场景清单，如 `672条硬核循证法则 · 顶级AI实操避坑 · 降维吊打万级付费智商税`；
* **Tier 4 (权威背书徽章 Badge)**：黑金质感胶囊，如 `★ GitHub 120,000+ Stars 封神级开源双壁 ★`、`★ 纯本地极简开源 · 零商业API收费 ★`；
* **Tier 5 (利益保障药丸 Pill)**：翡翠绿（`#2A9D8F`）药丸，如 `纯手搓无套路 · 全开源永久免费 · 拒绝焦虑`。

### 3. 分镜双轨戏剧反差
* **左侧痛点反差**：火柴人愤怒/痛快地将带有打叉 ❌ 的垃圾桶踢翻（把“2999元水课PPT”、“流氓弹窗”、“高额扣费账单”踩入垃圾桶）；
* **右侧工匠实操**：从容淡定的极客火柴人戴眼镜、喝咖啡，在工作台拼装清晰的积木模块，电脑屏幕显示清晰的数据图表与拓扑。

### 4. 底色规范（摒弃廉价大黄底）
默认首选**科技杂志冷灰白（#F5F6F8）**，带来类似 Wired / 图灵 / O'Reilly 特刊的高级出版物审美（硬核底层主题可选 Slate 极客暗黑 `#0F172A`）。背景必须为 100% 纯色平铺，严禁白框、粗糙网格或上下黑边，确保补色与自动缩放无缝。

### 5. 微信 2.35:1 居中裁切防线
微信订阅号消息流大图强制按 **2.35:1 居中自动裁切**（即 16:9 画布上下各砍约 14% 高度）。画布顶部 0~18% 区域（y < 100px）与底部 0~15% 严禁放置文字或主体人脸；所有关键元素必须收敛在**垂直中段 65% 安全视窗**内。

`upload_to_wechat.py` 内置 `ensure_safe_crop_cover` 智能像素分析与防呆重构，若检测到文字贴顶，自动执行居中安全缩放与纯色背景无缝延伸，确保 100% 完整露字。
