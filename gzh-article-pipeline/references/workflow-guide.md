# GZH Article Pipeline 工作流详解

本指南详细记录了从原始素材到微信公众号草稿箱的标准化 4 步作业流程。

---

## 阶段一：视觉锚点规划 (Visual Anchoring)
- **输入形式**：技术文档、博客文章、会议演讲稿、URL 链接。
- **规划原则**：
  - 避免“每一段都配图”，只在核心论点转折、架构对比与闭环机制处设锚点；
  - 采用 **16:9 画幅**，黑白线稿 + 1 个点缀色（科技蓝或终端绿）；
  - 输出标准 Shot List 表格，包含动作、情绪、主要物件和显式标签。
- **人机对齐**：必须由用户确认配图方案后方可触发绘图与正文编写。

---

## 阶段二：去 AI 味人性化写作 (Humanized Writing)
- **拒绝模版化**：去除“作为...的见证”、“不可磨灭的印记”、“不仅...而且...”、“毫无疑问”等 LLM 高频套话。
- **增加工程质感**：直面复杂性，讲清楚方案的权衡（Trade-off）、真实痛点与踩坑经验。
- **图文互锁**：正文叙述与火柴人插图中的动作隐喻紧密交织。

---

## 阶段三：公众号合规排版 (WeChat Layout Engine)
- **内联样式**：所有 CSS 全部内联至标签的 `style` 属性中，严禁全局 `<style>`。
- **防丢失包裹**：所有文本节点必须严格使用 `<span leaf="">` 包裹，避免复制粘贴至微信富文本编辑器时丢失字体和边框样式。
- **校验清零**：运行校验脚本，确保 0 Error 0 Warning。

---

## 阶段四：官方 API 草稿箱直连 (WeChat API Automation)
- **接口 1**：`GET /cgi-bin/token` 获取凭证。
- **接口 2**：`POST /cgi-bin/media/uploadimg` 上传正文图片至腾讯 CDN（永久有效且不占素材库配额）。
- **接口 3**：`POST /cgi-bin/material/add_material` 上传封面图片获取 `thumb_media_id`。
- **接口 4**：`POST /cgi-bin/draft/add` 提交最终图文。
