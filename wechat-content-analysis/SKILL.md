# 微信公众号发表数据与公私域流量诊断专家技能 (WeChat Content Analysis Skill)

本技能提供**一键自动化微信公众号后台发表数据全量抓取、公私域渠道透视（算法推荐流 vs 常读粉丝消息 vs 群会话）、爆款与低阅分层归因诊断**。

---

## ⚡️ 核心自动化工具（一键拉取与诊断）

当用户提出查看/拉取/分析公众号数据时，**必须直接运行以下脚本**获取最新真实后台数据，无需让用户手动截图或手动报数：

```bash
# 默认精准分析最近 30~40 篇已发表文章并聚合渠道数据 (执行仅需 3~5 秒)
python3 /Users/qcc/.gemini/config/skills/wechat-content-analysis/scripts/pull_and_analyze_mp.py --limit 30

# 若需全量拉取全号所有历史文章：
python3 /Users/qcc/.gemini/config/skills/wechat-content-analysis/scripts/pull_and_analyze_mp.py --all

# 若需强制刷新所有本地缓存：
python3 /Users/qcc/.gemini/config/skills/wechat-content-analysis/scripts/pull_and_analyze_mp.py --refresh
```

### 自动化脚本核心能力：
1. **自动连接本地 Chrome 微信公众平台标签页**（免扫码、免登录凭据泄漏风险）。
2. **账号全盘画像**：实时总粉丝数、昨日阅读人次、昨日分享、周报公域推荐阅读聚合。
3. **单篇「发表数据」全渠道透视**：提取每篇文章在推荐流（公域看一看）、公众号消息（常读私域）、聊天会话（群转发）中的真实 UV 占比。
4. **科学分层归因矩阵**：
   - 爆款破圈池（阅读 $\ge$ 1,000）：推荐占比通常 $\ge$ 90%；
   - 私域低阅池（阅读 < 300）：推荐占比通常 < 5%（算法推荐熔断），阅读量被困在常读粉丝盘（80~120 阅）。

[运行 pull_and_analyze_mp.py 获取数据] ➔ [1. 渠道分层归因] ➔ [2. 内容与心理学拆解] ➔ [3. 提炼读者画像偏好] ➔ [4. 输出下期落地选题方案]

### 第一步：全链路流量漏斗诊断

根据用户提供的数据，比对行业基准线快速定位瓶颈：

| 关键指标 | 行业均值参考 | 偏低时的核心病因 | 针对性排查方向 |
| :--- | :--- | :--- | :--- |
| **打开率**（阅读量 / 送达人数） | 3% ~ 8% | 标题吸引力不足、封面无辨识度、选题脱离常读粉丝关注点 | 标题是否过于平淡/行业术语过多？封面是否缺乏视觉焦点？ |
| **完读率**（读完人数 / 打开人数） | 20% ~ 40% | 开头前 200 字无钩子、中段信息密度断崖、段落过长视觉疲劳 | 开头是否自说自话？中段是否有枯燥的论述？ |
| **分享率**（分享转发 / 阅读量） | 1% ~ 5% | 缺乏“社交货币”（无谈资/无利他价值/无情绪共鸣） | 读者读完后，发到朋友圈或微信群的动机是什么？ |
| **在看/点赞率** | 1% ~ 3% | 观点未击中痛点，读者认同感较弱 | 文中是否有让人想摘录、标记的金句或干货？ |
| **涨粉转化率**（新增关注 / 阅读量） | 0.5% ~ 2% | 底部缺乏关注引导，或文章未体现账号的持续价值定位 | 结尾是否有明确钩子（如资料领取、系列预告、鲜明人设）？ |

### 第二步：文章内容与读者心理诊断

1. **标题与封面诊断**：
   - 是否包含：痛点词、数字锚点、好奇缺口、价值承诺？
   - 是否存在：标题党（导致完读率断崖）、自嗨型标题（导致打开率低）？
2. **开头 200 字（黄金留存区）**：
   - 是否在前 3 句话点明核心冲突或读者痛点？
   - 是否存在冗长的客套话、自我介绍或无意义背景铺垫？
3. **中段行文节奏（留存与完读）**：
   - 视觉排版：每屏是否有小标题、加粗重点、金句隔离？
   - 认知负荷：长难句是否过多？专业概念是否缺乏通俗比喻？
4. **文末与转化触点（CTA）**：
   - 文末总结是否利于读者直接收藏/转发备用？
   - 评论区互动提问是否门槛过高（读者不知道该评论什么）？

### 第三步：受众画像与兴趣偏好提炼

结合用户画像（年龄、性别、地域）与流量来源深度分析：
1. **年龄与性别结构透视**：
   - **36~60 岁高知男性为主（占 70%+）**：典型的资深职场中坚、技术管理者、企事业单位骨干。
     - **痛点特征**：受够了繁琐的“数字脏活”（乱码文档、Excel 卡死、多系统数据汇总），渴望开箱即用，反感折腾与套壳噱头；
     - **转发动机**：管理型转发（发给团队当下属工作抓手）或品味型转发（证明自己认知超前）；
     - **大忌**：严禁写纯晦涩底层小众代码（受众千分之几、零社交货币），严禁营销号震惊体。
   - **18~25 岁年轻人极低（< 5%）**：拒绝二次元/考研/搞钱副业等轻浮选题，主打生产级降维提效。
2. **纯技术 vs 实用工具的传播漏斗诊断模型**：
   - **纯技术文章（冷门排障/底层代码）**：受众仅千分之一，读者解决完 Bug 关掉页面，不转发、不认号主，关注转化率 < 0.2%；
   - **实用生产力工具文章（降维打击）**：人人都有痛点，具备极强利他属性与群聊转发动力，文章页关注率可达 80%+，取关率趋近于 0。
3. **流量来源构成诊断**：
   - **文章页关注占比高（> 80%）**：深度内容信任驱动，读者是读到了具有极强信息增量的深度长文主动关注，粘性极高；
   - **搜一搜占比高（> 10%）**：命中高价值长尾技术与工具词，具备公域 SEO 持续造血能力；
   - **朋友圈/好友会话占比高**：具备极强的社交货币与利他价值。

### 第四步：输出标准复盘报告与下期建议

每次复盘向用户交付以下结构的完整报告：

```markdown
# 📊 【公众号文章复盘诊断报告】

## 一、核心数据与漏斗评级
- 流量健康度评分（综合评级 A/B/C/D）
- 关键漏斗流失点定位（标题端 / 内容留存端 / 互动裂变端）

## 二、上期得失深度拆解
- 亮点保留：哪些表达、结构或观点起到了正向拉动作用？
- 痛点改进：导致跳出或低分享的具体段落与原因。

## 三、读者画像与偏好洞察
- 本期读者对什么最敏感（关键词、情绪点、实用工具）？
- 本期读者排斥或无感的内容形式是什么？

## 四、下期具体执行策略调整
- **开头优化动作**：下期开头采用何种钩子（故事/数据/痛点/反常识）？
- **排版与互动优化**：文末互动问题与转发诱因设计。

## 五、下期 3 个定制化候选选题（高转化方案）
每个选题必须包含：
1. 【候选标题】（提供 3 个不同风格变体：痛点型 / 悬念好奇型 / 干货清单型）
2. 【核心切入点与大纲】（前言钩子 + 3个核心要点 + 结论行动点）
3. 【预期受众与传播动机】（读者为什么会点开、为什么会转发）
```
