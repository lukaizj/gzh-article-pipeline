# 爆款选题与标题生成库（下期建议专用）

## 1. 痛点共鸣型
- **公式**：[目标人群] + [高频困境] + [反常规出路/解决方案]
- **示例**：
  - “做了3年公众号，我终于放弃了这套无效的‘日更’模式”
  - “为什么你写了那么多干货，读者却从来不转发？”

## 2. 实用清单与工具型
- **公式**：[数字量化] + [核心收益] + [即开即用/懒人包]
- **示例**：
  - “建议收藏！5个自媒体人必备的数据复盘工具与提效技巧”
  - “照着抄就行：一份能让完读率提升50%的排版检查清单”

## 3. 认知反差与好奇缺口型
- **公式**：[颠覆常识的结论] + [背后的深层逻辑/真相]
- **示例**：
  - “阅读量10w+并不值钱，这类指标才是公众号的隐形金矿”
  - “被严重低估的搜一搜流量：普通人如何靠长尾词持续涨粉？”
